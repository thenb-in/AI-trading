# 5. Help & troubleshooting {#help-and-troubleshooting}

## Help & support {#help-support}

Raise a support ticket with context attached.

1. Open the help dialog — **⌥H / F1** (Alt+H / F1), or the help button.
2. Describe the issue.
3. A screenshot of the current screen is captured automatically, and recent console logs are attached for debugging.
4. Submit.

## Common problems {#common-problems}

| Symptom | Cause | What to do |
|---------|-------|------------|
| Can't sign in right after signing up | Account is pending approval | Wait for an administrator to approve it |
| "Account not found" on login | The account was deactivated | Ask an administrator to reactivate it |
| Forced to change password on login | It is your first login | Set the new password and continue |
| A password reset left the account pending | Reset was done without a two-factor code | An administrator must re-approve it |
| A screen or menu is missing | Your role does not have that permission | Ask an administrator to add it to your role |
| Can't switch to a company | Your account is not linked to it | Ask an administrator to link you |
| The session list looks stale | It does not refresh on its own | Reload the page for a newer picture |
