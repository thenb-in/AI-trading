# 2. Finding your way around {#finding-your-way-around}

Every screen is reached the same way, and every list behaves the same way. Learn it once.

## The navigator {#navigator}

The navigator is the map of the app — every module, report and master, with the ones you can open and the ones your role does not reach. Use it to jump straight to a screen instead of hunting through menus.

## Master screens {#masters}

A **master** is a list of one kind of record (users, roles, places, files, and so on). Masters are grouped on the masters page; open one to see its list.

Every master list shares the same toolbar and row actions:

- **New** — add a record.
- **Edit** — open a row to change it.
- **Export / Import** — pull the list out, or load records in (where offered).
- **Refresh** — reload the list.
- **Status filter** — narrow the list by state.

## Working in a list {#data-grid}

Lists are shown in a data grid. In any grid you can:

- Search, sort and filter.
- Show, hide, reorder and resize columns.
- Go **fullscreen** to use the whole window.
- Export the visible rows.

### Saved layouts {#layouts}

A **layout** remembers a grid's columns — which show, their order, their widths.

- **Create** — open the layout toolbar, **Create layout**, name it, arrange the columns, choose **Private** (only you) or **Public** (everyone in the company), and save.
- **Set default** — mark a layout as default and it applies automatically whenever you open that grid.
- **Switch** — pick another layout from the toolbar; the grid updates at once.

## Global search {#global-search}

Search across every module from one box.

1. Open the search palette — **⌥S** / **⌘K** (Alt+S / Ctrl+K).
2. Type what you are looking for.
3. Results from every module appear; pick one to go straight there.

## Keyboard shortcuts {#shortcuts}

Every shortcut is also shown on the button that does the same thing — hover to see it. Mac first, Windows/Linux in brackets.

| Action | Mac | Windows / Linux | Where |
|--------|-----|-----------------|-------|
| New record | ⌥N | Alt+N | Any master page |
| Save / submit | ⌘S | Ctrl+S | Any open form |
| Close dialog | Esc | Esc | Any dialog |
| Refresh | ⌥R | Alt+R | Any master page |
| Export | ⌥E | Alt+E | Pages offering export |
| Import | ⌥I | Alt+I | Pages offering import |
| Apply filters | ⌥↩ | Alt+Enter | Any filter panel |
| Global search | ⌥S / ⌘K | Alt+S / Ctrl+K | Anywhere |
| Help & support | ⌥H / F1 | Alt+H / F1 | Anywhere |
| Grid fullscreen | ⌥F | Alt+F | Any data grid |

While a dialog is open, page-level shortcuts stand down — **New** never discards the record you are editing.

## Switching company {#company-switch}

When your account is linked to more than one company:

1. Open the company switcher (sidebar or header).
2. Pick a different company.
3. The app reloads under that company. Your permissions and device access follow the new company's settings.

You can only switch to a company you are linked to.
